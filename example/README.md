# Card Fan Spread Demo

## Preview

```bash
cd example
flutter run
```

Online demo: <https://runoob-coder.github.io/card-fan-spread-widget/>

The demo lets you switch between the three spreading styles, play / replay /
collapse the deck, flip between card faces and backs, and tweak fan angle,
double-tier offset (giant fan), overlap density, arc lift, card count, duration
and stagger in real time.
